# 思维导图

这是从 DeepConvo 中独立迁移的思维导图 Quicker 动作，保留原版思维导图界面、编辑交互和收藏夹文件夹功能。

## 功能

- 点击动作直接打开独立思维导图窗口。
- 使用原版节点编辑、连线、缩放、导入导出和快捷键。
- 使用收藏夹管理思维导图及文件夹层级。
- 界面固定为简体中文。
- 工具栏可切换亮色或暗色模式，下次打开时自动恢复上次选择。
- 用户数据保存在 Quicker 动作变量 `app_data_json` 中，不依赖浏览器缓存或外部数据文件。
- 应用资源随动作离线提供，并针对 WebView2 去除重复的旧字体格式，使动作保持在 Quicker 的 5 MB 限制内。
- 自动记忆窗口尺寸、位置和最大化状态。

## 数据说明

收藏夹、文件夹、思维导图正文、视图状态及亮暗模式选择会序列化到动作变量中。首次启动时，动作只会在本机应用数据目录释放 WebView2 所需的静态界面资源；该目录不保存用户思维导图数据。

建议在关闭窗口前保存新建的思维导图。已保存的思维导图会在编辑过程中继续写回 Quicker 动作变量。

## 系统要求

- Windows 10 或 Windows 11
- Quicker
- Microsoft Edge WebView2 Runtime
